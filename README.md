# odoo-account

Accounting modules for Odoo, by **TaghrasTech**.

Branch naming follows Odoo major versions (this is the **`18.0`** branch).

## Modules

| Module | Summary |
|--------|---------|
| [`tt_account_refund_name_prefix`](tt_account_refund_name_prefix/) | Share one number sequence between invoices and credit notes while keeping a distinct prefix on credit notes (e.g. `F` / `FA`). Extends OCA `account_move_name_sequence`. |
